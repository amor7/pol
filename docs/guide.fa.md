# راهنمای منوی پل، قدم به قدم

**[بازگشت به README](../README.fa.md)**

روی هر سرور فقط بنویسید `pol` و Enter بزنید. یک منوی شماره‌دار باز می‌شود. عدد گزینه را بنویسید و Enter بزنید. `0` خروج است. بعد از هر کار با Enter به منو برمی‌گردید.

روی هر شماره کلیک کنید تا به توضیح همان گزینه بروید.

## اولین بار: منوی شروع

اگر پل هنوز روی سرور راه‌اندازی نشده باشد، منو فقط دو گزینه دارد:

- **۱) Set up this machine as the server**: روی **سرور خارج** این را بزنید. یک پورت آزاد برای تونل انتخاب می‌کند، سرویس را راه می‌اندازد، پورت‌هایی را که باید در فایروال باز کنید نشان می‌دهد و یک **توکن** (`pol1_...`) چاپ می‌کند. توکن را کپی کنید.
- **۲) Set up this machine as the relay**: روی **سرور ایران** این را بزنید. توکن را می‌پرسد (paste کنید)، بعد پورت‌هایی را که می‌خواهید منتقل شوند (مثلاً `2088`).

## منوی سرور ایران

<a id="r1"></a>
### 1) Status: وضعیت

همه‌چیز را در یک صفحه نشان می‌دهد:
- هر حالت تونل وصل است یا نه (`up` یا خطا)، پینگش، و چند اتصال آماده دارد؛
- پورت‌ها، حالت هر کدام، تعداد کاربرهای وصل و ترافیکشان؛
- اگر auto دارید، رتبه‌بندی حالت‌ها.

**کی بزنم؟** هر وقت کاربرها گفتند وصل نمی‌شوند، اول این را ببینید.

[↑ فهرست](#toc)

<a id="r2"></a>
### 2) Add ports: اضافه کردن پورت

سه سؤال می‌پرسد:
1. **پورت‌ها:** مثلاً `2088`. چند تا با فاصله: `2088 8443`. بازه: `2080-2085`. اگر پورت سرور خارج فرق دارد: `2088:443` (پورت 2088 اینجا به پورت 443 خارج).
2. **پروتکل:** `1` فقط TCP (برای بیشتر کانفیگ‌ها، مثل VLESS و VMess و Trojan)، `2` فقط UDP (برای Hysteria2 و TUIC و WireGuard)، `3` هر دو.
3. **حالت تونل:** لیست شماره‌دار همهٔ حالت‌ها می‌آید. عدد را بزنید. اگر مطمئن نیستید Enter بزنید تا پیش‌فرض (tls) انتخاب شود. بعداً با [گزینهٔ ۵](#r5) عوض می‌شود.

پورت همان لحظه فعال می‌شود. در کانفیگ کاربرها فقط آدرس سرور خارج را با آدرس سرور ایران عوض کنید.

[↑ فهرست](#toc)

<a id="r3"></a>
### 3) Remove ports: حذف پورت

لیست پورت‌ها را نشان می‌دهد و می‌پرسد کدام را حذف کند. `2088` هم TCP و هم UDP آن را حذف می‌کند. `2088/udp` فقط UDP را. کاربرهای آن پورت همان لحظه قطع می‌شوند.

[↑ فهرست](#toc)

<a id="r4"></a>
### 4) List ports: لیست پورت‌ها

پورت‌ها را با حالت تونلشان، تعداد اتصال‌های زنده و ترافیکشان نشان می‌دهد.

[↑ فهرست](#toc)

<a id="r5"></a>
### 5) Change the tunnel mode: عوض کردن حالت تونل

لیست پورت‌ها را نشان می‌دهد، می‌پرسد کدام پورت (یا چند تا با فاصله)، بعد لیست حالت‌ها را نشان می‌دهد که عددش را بزنید.

**همان لحظه اعمال می‌شود:** کاربرهای آن پورت قطع می‌شوند و در یکی دو ثانیه از راه جدید وصل می‌شوند. بقیهٔ پورت‌ها دست نمی‌خورند.

کدام حالت را انتخاب کنم؟ [راهنمای انتخاب در README](../README.fa.md#choose) را ببینید. خلاصه: برای استفادهٔ عادی **shield** یا **mux**، برای بازی **quic** یا **kcp**.

[↑ فهرست](#toc)

<a id="r6"></a>
### 6) Speed test: تست سرعت

سرعت دانلود و آپلود **همهٔ حالت‌ها** را از مسیر واقعی بین دو سرور می‌سنجد (۲۰ مگ هر طرف، با ۴ اتصال هم‌زمان مثل گوشی)، از سریع به کند مرتب می‌کند و مصرف هر کدام را هم کنارش می‌نویسد. چند دقیقه طول می‌کشد.

حالتی که `failed` بنویسد روی مسیر شما کار نمی‌کند. دلیلش هم کنارش نوشته می‌شود.

**نکته:** تست، ترافیک واقعی مصرف می‌کند (حدود ۴۰ مگ برای هر حالت، روی هم چند صد مگ). برای تست فقط یک حالت از دستور استفاده کنید: `pol speedtest --mode shield`

[↑ فهرست](#toc)

<a id="r7"></a>
### 7) Ping: پینگ

زمان رفت و برگشت از داخل تونل تا سرور خارج را نشان می‌دهد. اگر جواب نداد، تونل قطع است: [وضعیت](#r1) و [لاگ](#c1) را ببینید.

[↑ فهرست](#toc)

<a id="r8"></a>
### 8) All tunnel modes: لیست همهٔ حالت‌ها

همهٔ حالت‌ها را گروه به گروه، با کاربرد و مصرف هر کدام نشان می‌دهد. چیزی را عوض نمی‌کند. همان جدول‌های [README](../README.fa.md#modes) است.

[↑ فهرست](#toc)

<a id="r9"></a>
### 9) Reverse mode: راه‌اندازی reverse

فقط وقتی لازم است که **اتصال از ایران به خارج بسته باشد** ولی برعکسش باز باشد. یک پورت روی سرور ایران باز می‌کند و یک خط `pol link pol1r_...` چاپ می‌کند.

1. آن خط را کپی کنید و روی **سرور خارج** بزنید (یا در منوی سرور خارج [گزینهٔ ۴](#s4)).
2. پورت‌ها را روی حالت `reverse` بگذارید ([گزینهٔ ۵](#r5)).

[↑ فهرست](#toc)

<a id="r10"></a>
### 10) Camo: سایت camo

حالت camo، TLS یک سایت واقعی را قرض می‌گیرد (پیش‌فرض `www.microsoft.com`). اینجا می‌توانید سایت را عوض کنید. اگر خالی Enter بزنید، فقط سایت فعلی را نشان می‌دهد.

**مهم:** همان سایت را روی **سرور خارج** هم بگذارید ([گزینهٔ ۶ خارج](#s6))، وگرنه camo وصل نمی‌شود. سایتی بزرگ انتخاب کنید که در ایران فیلتر نیست.

[↑ فهرست](#toc)

<a id="r11"></a>
### 11) SNI: اسمی که اتصال نشان می‌دهد

هر اتصال TLS پل یک اسم سایت نشان می‌دهد که ناظر می‌بیند. پیش‌فرض یک سایت بزرگ است که خودکار انتخاب می‌شود (مثل `www.apple.com`).

- **بهترین کار:** یک دامنه دارید؟ رکورد A آن را روی آی‌پی **سرور خارج** بگذارید و اینجا همان دامنه را بنویسید. این‌طوری اسم و آی‌پی با هم جور درمی‌آیند و کمتر جلب توجه می‌کند.
- `default` به انتخاب خودکار برمی‌گرداند.
- خالی Enter: فقط اسم فعلی را نشان می‌دهد.

فقط روی سرور ایران لازم است.

[↑ فهرست](#toc)

<a id="r12"></a>
### 12) DNS mode: حالت DNS (اضطراری)

برای روزی که **هیچ چیز جز DNS** بیرون نمی‌رود. خیلی کند است (ده‌ها تا چند صد کیلوبیت) و مصرف زیادی دارد. دامنه و یک DNS سرور می‌پرسد (پیش‌فرض `8.8.8.8`).

قبلش باید دامنه و سرور خارج را آماده کرده باشید: [راه‌اندازی dns در README](../README.fa.md#dns).

[↑ فهرست](#toc)

<a id="r13"></a>
### 13) CDN: فرستادن ws و xhttp از Cloudflare

برای وقتی **آی‌پی سرور خارج از ایران فیلتر شده**. ترافیک حالت‌های ws، xhttp و shield-cdn از Cloudflare رد می‌شود. یک دامنه می‌پرسد که در Cloudflare (با ابر نارنجی روشن) به آی‌پی سرور خارج اشاره می‌کند. `off` خاموشش می‌کند.

مراحل کامل: [CDN در README](../README.fa.md#cdn). بعد پورت را روی `xhttp`، `ws` یا `shield-cdn` بگذارید.

[↑ فهرست](#toc)

## منوی سرور خارج

<a id="s1"></a>
### 1) Status: وضعیت

نشان می‌دهد سرویس روشن است، روی کدام پورت‌ها گوش می‌دهد (همان‌هایی که باید در فایروال شرکت سرور باز باشند)، چند سرور ایران وصل است و ترافیکشان چقدر است. اگر reverse یا via دارید، وضعیت آن‌ها هم اینجاست.

[↑ فهرست](#toc)

<a id="s2"></a>
### 2) Show the token: نمایش توکن

توکن (`pol1_...`) و دستور نصب کامل برای سرور ایران را دوباره چاپ می‌کند. وقتی سرور ایران جدید می‌گیرید یا توکن را گم کرده‌اید، این را بزنید. **توکن رمز تونل است؛ به کسی ندهید.**

[↑ فهرست](#toc)

<a id="s3"></a>
### 3) Make a new token: ساختن توکن جدید

رمز تونل را عوض می‌کند. **همهٔ سرورهای ایرانی که با توکن قبلی وصل بودند قطع می‌شوند** تا توکن جدید را بگیرند. وقتی لازم است که فکر می‌کنید توکن لو رفته.

بعدش روی هر سرور ایران: `pol` ← [راه‌اندازی دوباره](#c6) ← `2` (Iran) ← توکن جدید را paste کنید. پورت‌ها می‌مانند.

[↑ فهرست](#toc)

<a id="s4"></a>
### 4) Reverse mode: link a relay: وصل کردن reverse

خطی را که [گزینهٔ ۹ سرور ایران](#r9) چاپ کرده paste کنید (`pol1r_...`). از این به بعد سرور خارج خودش به سرور ایران وصل می‌شود.

[↑ فهرست](#toc)

<a id="s5"></a>
### 5) Middle hop (via): سرور واسط

وقتی آی‌پی سرور اصلی فیلتر است، می‌توانید یک سرور خارجی دوم با آی‌پی تمیز وسط بگذارید. این گزینه را روی **سرور واسط** بزنید و توکن **سرور اصلی** را paste کنید. به سرور ایران توکن سرور واسط را بدهید. `off` خاموشش می‌کند. توضیح کامل: [سرور واسط در README](../README.fa.md#via).

[↑ فهرست](#toc)

<a id="s6"></a>
### 6) Camo: سایت camo

همان [گزینهٔ ۱۰ سرور ایران](#r10). سایت باید روی هر دو سرور یکی باشد.

[↑ فهرست](#toc)

<a id="s7"></a>
### 7) DNS mode: حالت DNS

دامنه‌ای را می‌پرسد که رکورد NS آن به این سرور اشاره می‌کند. پورت UDP 53 باید آزاد باشد. `off` خاموشش می‌کند. بعد روی سرور ایران [گزینهٔ ۱۲](#r12).

[↑ فهرست](#toc)

<a id="s8"></a>
### 8) Reverse mode: unlink: قطع کردن reverse

سرورهای ایرانی وصل‌شده با reverse را نشان می‌دهد و می‌پرسد کدام را قطع کند (`all` همه را).

[↑ فهرست](#toc)

## گزینه‌های مشترک (هر دو سرور)

<a id="c1"></a>
### Logs: لاگ زنده

پیام‌های سرویس را زنده نشان می‌دهد: وصل و قطع شدن حالت‌ها و خطاها. **Ctrl+C** لاگ را می‌بندد و به منو برمی‌گردد. برای فقط خطاها از دستور استفاده کنید: `pol logs -e`

[↑ فهرست](#toc)

<a id="c2"></a>
### Restart: ری‌استارت

سرویس را از نو راه می‌اندازد. همهٔ کاربرها چند ثانیه قطع می‌شوند. معمولاً لازم نیست، چون تغییرات خودشان اعمال می‌شوند.

[↑ فهرست](#toc)

<a id="c3"></a>
### Stop / Start: توقف یا روشن کردن

اگر سرویس روشن باشد، اسم گزینه **Stop** است و خاموشش می‌کند. اگر خاموش باشد، **Start** است و روشنش می‌کند. بالای منو هم نوشته `running` (روشن) یا `stopped` (خاموش).

[↑ فهرست](#toc)

<a id="c4"></a>
### Speed up the network (BBR): سریع‌تر کردن شبکه

BBR و بافرهای بزرگ‌تر شبکه را در لینوکس روشن می‌کند. معمولاً سرعت را روی مسیرهای دور و پرافت خیلی بهتر می‌کند. **یک بار روی هر دو سرور بزنید.** بعد از ری‌استارت سرور هم می‌ماند.

[↑ فهرست](#toc)

<a id="c5"></a>
### Update pol: به‌روزرسانی

آخرین نسخه را از GitHub می‌گیرد و نصب می‌کند. تنظیمات و پورت‌ها می‌مانند. **همیشه روی هر دو سرور بزنید**، چون نسخه‌های خیلی متفاوت ممکن است با هم وصل نشوند.

اگر سرور ایران به GitHub دسترسی ندارد: [نصب بدون گیت‌هاب](../README.fa.md#offline).

[↑ فهرست](#toc)

<a id="c6"></a>
### Set up again: راه‌اندازی دوباره

نصب را از اول انجام می‌دهد (اول می‌پرسد مطمئنید یا نه). برای وقتی که توکن جدید گرفته‌اید یا می‌خواهید نقش سرور را عوض کنید.

روی سرور ایران **پورت‌ها می‌مانند**، ولی تنظیم‌های camo، SNI، CDN، reverse و dns پاک می‌شوند و باید دوباره بزنید.

[↑ فهرست](#toc)

<a id="c7"></a>
### Uninstall: حذف کامل

سرویس را متوقف می‌کند و پل را با تنظیماتش از سرور پاک می‌کند. قبلش تأیید می‌گیرد.

[↑ فهرست](#toc)

<a id="howto"></a>
## کارهای رایج

**کاربرها وصل نمی‌شوند.**
[وضعیت](#r1) را روی سرور ایران ببینید. اگر حالتِ آن پورت خطا دارد، [تست سرعت](#r6) بزنید و پورت را روی حالتی بگذارید که کار می‌کند ([گزینهٔ ۵](#r5))، یا روی `auto`. اگر همهٔ حالت‌ها خطا دارند: سرور خارج روشن است؟ ([وضعیت خارج](#s1)). نسخهٔ دو سرور یکی است؟ ([به‌روزرسانی](#c5)).

**سرعت کم است.**
[BBR](#c4) را روی هر دو سرور بزنید، بعد [تست سرعت](#r6). سریع‌ترین حالت را انتخاب کنید.

**نگرانم سرور ایران «ایران اکسس» شود.**
پورت را روی `shield` یا `camo` یا `mux` بگذارید. اگر دامنه دارید، [SNI](#r11) را تنظیم کنید. حجم سنگین را روی kcp و hop و faketcp نگذارید.

**آی‌پی سرور خارج فیلتر شد.**
[CDN](#r13) را راه بیندازید و پورت را روی `shield-cdn` یا `xhttp` بگذارید، یا یک [سرور واسط](#s5) بگذارید.

**می‌خواهم برای بازی پینگ کمتری داشته باشم.**
یک پورت UDP اضافه کنید ([گزینهٔ ۲](#r2)، پروتکل `2` یا `3`) و حالتش را `quic` بگذارید. اگر بد بود، `kcp` (مصرف بیشتری دارد).

[↑ فهرست](#toc)
