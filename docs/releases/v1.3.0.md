## هشت حالت تونل، پورت UDP، و تست سرعت همهٔ حالت‌ها

### حالت‌های جدید
| حالت | چطور | به درد چه می‌خورد |
|---|---|---|
| **split** | هر اتصال کاربر هم‌زمان روی ۴ اتصال TLS پخش می‌شود | اینترنتی که سرعت هر اتصال را جدا محدود می‌کند: حتی یک دانلود به سرعت چند اتصال می‌رسد |
| **quic** | جریان‌های یک اتصال QUIC روی UDP | مسیرهای پر از بسته‌گم‌شدن |
| **obfs** | TCP با رمز AES، بدون دست‌دادن TLS | از اولین بایت شبیه دادهٔ تصادفی؛ جلوی پخش دوبارهٔ ضبط‌شده هم گرفته می‌شود |
| **ws** | یک WebSocket برای هر اتصال | **رد شدن از Cloudflare** وقتی آی‌پی سرور خارج فیلتر شده (`pol cdn`) |
| **reverse** | سرور خارج به سرور ایران وصل می‌شود | وقتی اتصال از ایران به خارج بسته است (`pol reverse` و `pol link`) |

حالت‌های قبلی (tls، mux، direct) هم سر جایشان هستند. همه به‌جز reverse و direct از همان یک پورت تونل استفاده می‌کنند.

### پورت UDP
- `pol add 443/udp --mode quic` یا `pol add 2096 --both`. حالا Hysteria2، TUIC، WireGuard و KCP هم از سرور ایران رد می‌شوند.

### تست سرعت
- **`pol speedtest`** همهٔ حالت‌ها را از مسیر واقعی، با چهار اتصال هم‌زمان، می‌سنجد و سریع‌ترین را معرفی می‌کند. `--mode` فقط یک حالت را می‌سنجد.

### بقیه
- `pol status` وضعیت هر هشت حالت را جداگانه نشان می‌دهد. روی سرور خارج هم quic و اتصال‌های reverse نمایش داده می‌شوند.
- منو: انتخاب TCP، UDP یا هر دو موقع اضافه کردن پورت؛ لیست کامل حالت‌ها با توضیح؛ گزینه‌های reverse، Cloudflare و link.
- هر کس بدون رمز به پورت تونل وصل شود، صفحهٔ معمولی nginx می‌بیند. در obfs هیچ جوابی نمی‌گیرد.

**به‌روزرسانی:** روی **هر دو سرور** `pol update` بزنید. روی سرور خارج، **پورت تونل را برای UDP هم باز کنید** (برای quic). اگر ufw فعال باشد، آپدیت خودش بازش می‌کند، ولی فایروال پنل شرکت سرور را باید خودتان باز کنید.

<details open><summary>English</summary>

**New modes:** split (one connection over 4 TLS connections at once - beats per-connection throttling), quic (QUIC streams over UDP - copes best with loss), obfs (AES-encrypted TCP with no TLS handshake, replay-protected - looks like noise), ws (a WebSocket per connection - can go through Cloudflare with `pol cdn`), reverse (the server connects to the relay - `pol reverse` / `pol link`). tls, mux and direct remain.

**UDP ports:** `pol add 443/udp --mode quic`, `pol add 2096 --both` - Hysteria2, TUIC, WireGuard and KCP now pass through the relay.

**Speed test:** `pol speedtest` measures every mode through the real path, four connections at once, and names the fastest; `--mode` measures one.

**Also:** `pol status` shows each mode's state (and quic and reverse links on the server); the menu asks TCP/UDP/both, lists all modes, and has reverse, Cloudflare and link items; probes see nginx, and obfs probes see nothing.

**Update:** `pol update` on **both** servers. On the server, **open the tunnel port for UDP too** (quic mode): the update does it in ufw; a firewall in your provider's panel you open yourself.
