## حالت‌های تونل: tls، mux و direct

حالا هر پورت حالت تونل خودش را دارد:

| حالت | چطور | کی |
|---|---|---|
| **tls** (پیش‌فرض جدید) | هر اتصال کاربر یک اتصال TLS جدا، با چند اتصال از قبل آماده | انتخاب معمول: رمزگذاری‌شده و **خیلی سریع‌تر** روی مسیرهای پرافت و اینترنت‌هایی که سرعت هر اتصال را محدود می‌کنند |
| **mux** (حالت قبلی) | همه داخل چند اتصال HTTP/2 | پنهان‌ترین حالت، ولی روی مسیرهای بد کندتر |
| **direct** | TCP ساده مستقیم به پورت خارج | سریع‌ترین، بدون رمزگذاری اضافه |

- `pol add 2088 --mode tls`، و `pol mode 2088 tls` برای عوض کردن حالت پورت‌های موجود. تغییر همان لحظه برای اتصال‌های جدید اعمال می‌شود.
- **منو:** موقع اضافه کردن پورت حالت را می‌پرسد، و گزینهٔ جدید «Change the tunnel mode of ports» دارد.
- **`pol speedtest`** حالا tls و mux را کنار هم، با چهار اتصال هم‌زمان (مثل گوشی)، می‌سنجد.
- `pol status` و `pol list` حالت هر پورت و وضعیت اتصال‌های tls را نشان می‌دهند.
- حالت tls از همان پورت تونل قبلی استفاده می‌کند و پورت جدیدی لازم نیست.

**به‌روزرسانی:** روی **هر دو سرور** `pol update` بزنید. حالت tls به نسخهٔ جدید روی سرور خارج نیاز دارد. پورت‌هایی که قبلاً اضافه کرده‌اید روی mux می‌مانند. برای عوض کردنشان: `pol mode 2088 tls`.

---

<details open><summary>English</summary>

Each port now has its own tunnel mode:

- **tls** (new default): every user connection gets its own TLS connection, from a pool kept ready. Encrypted, and much faster on lossy or per-connection-throttled paths.
- **mux** (the previous behaviour): everything as streams inside a few HTTP/2 connections; the most discreet, slower on bad paths.
- **direct**: plain TCP straight to the port abroad; fastest, nothing added.

`pol add 2088 --mode tls`, and `pol mode 2088 tls` to change existing ports (applies to new connections at once). The menu asks for a mode when adding ports and has a new "Change the tunnel mode of ports" item. `pol speedtest` compares tls and mux side by side with four connections at once. `pol status` and `pol list` show each port's mode and the tls pool. tls uses the existing tunnel port.

**Update:** run `pol update` on **both** servers; tls mode needs the new version on the server. Ports added before stay on mux; switch them with `pol mode 2088 tls`.

</details>
