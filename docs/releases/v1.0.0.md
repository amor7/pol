## اولین نسخهٔ پل

انتقال پورت‌های TCP از سرور ایران به سرور خارج، از داخل یک تونل رمزگذاری‌شده.

- **نصب با یک دستور** روی هر دو سرور. سرور خارج یک خط دستور چاپ می‌کند که روی سرور ایران زده می‌شود.
- **مدیریت پورت‌ها:** `pol add 2088`، `pol add 2088:443`، `pol add 2080-2085`، `pol del 2088`، `pol list`. تغییرات همان لحظه و بدون قطع شدن بقیهٔ پورت‌ها اعمال می‌شوند.
- **تونل:** HTTP/2 روی TLS 1.3، با گواهی سنجاق‌شده و رمز. از بیرون یک اتصال HTTPS معمولی دیده می‌شود و هر کس بدون رمز وصل شود صفحهٔ 404 معمولی nginx می‌بیند.
- **پایداری:** هر اتصال کاربر بافر جدا دارد تا یک کاربر گیرکرده بقیه را معطل نکند. اتصال‌های قطع‌شده خودکار دوباره برقرار می‌شوند. پورت اشغال‌شده آن‌قدر امتحان می‌شود تا آزاد شود.
- **دستورهای کمکی:** `pol status`، `pol ping`، `pol speedtest`، `pol token`، `pol logs`، `pol tune` (روشن کردن BBR)، `pol update`، `pol uninstall`.
- فقط TCP: VLESS، VMess، Trojan، Reality، WebSocket، gRPC، SSH و... کار می‌کنند. UDP (Hysteria2، TUIC، KCP، WireGuard) نه.

<details open><summary>English</summary>

First release: forward TCP ports from a relay in Iran to a server abroad through one encrypted tunnel.

- **One-command install** on both servers; the server prints the line to run on the relay.
- **Port management:** `pol add 2088`, `pol add 2088:443`, `pol add 2080-2085`, `pol del 2088`, `pol list`. Changes apply at once, without dropping the other ports' users.
- **Tunnel:** HTTP/2 over TLS 1.3 with a pinned certificate and a secret. From outside it is an ordinary HTTPS connection; anyone without the secret gets nginx's 404 page.
- **Sturdy:** each user connection has its own window so a stuck user cannot hold up others; broken connections are redialled; a busy port is retried until it is free.
- **Helpers:** `pol status`, `pol ping`, `pol speedtest`, `pol token`, `pol logs`, `pol tune` (BBR), `pol update`, `pol uninstall`.
- TCP only: VLESS, VMess, Trojan, Reality, WebSocket, gRPC, SSH and so on work; UDP (Hysteria2, TUIC, KCP, WireGuard) does not.
