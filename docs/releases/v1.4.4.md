## برچسب‌های مصرف دقیق‌تر، و مصرف خیلی کمتر در حالت بی‌کار

**برچسب‌های مصرف حالا سه بخش دارند** (همه روی مسیر سالم اندازه‌گیری شده‌اند):

- **در انتقال**: به ازای هر بایت. هزینهٔ دانلودهای بزرگ همین است و برای حالت‌های TCP واقعاً حدود ٪۱ است.
- **هر اتصال**: هزینهٔ باز کردن یک اتصال. سایت‌ها و اپ‌ها اتصال‌های کوتاه زیادی باز می‌کنند، پس این عدد برایشان مهم‌تر است. tls حدود ۳٫۵ کیلوبایت و split حدود ۱۴ کیلوبایت، ولی obfs و mux فقط ۰٫۲ کیلوبایت.
- **در روز بی‌کار**: آماده نگه داشتن حالت وقتی کسی وصل نیست.

`pol modes` و منو همین سه عدد را نشان می‌دهند، و برچسب جدید «many short connections: web, apps» روی mux و obfs و ssh، و «big downloads» روی split آمده.

**پیشنهاد:** برای استفادهٔ عادی (سایت، اپ) پورت را روی **mux** یا **obfs** بگذارید، مثلاً `pol mode 2088 auto:mux,obfs,tls,xhttp`. split را برای دانلودهای حجیم نگه دارید.

**مصرف بی‌کار کم شد.** عددهای اندازه‌گیری‌شدهٔ فعلی برای هر حالت:

| حالت | مگ در روز |
|---|---|
| mux | ۲۴ |
| split | ۱۵ |
| tls | ۱۴ |
| ws | ۹ |
| kcp | ۸ |
| camo | ۷ |
| quic | ۵ |
| obfs | ۲٫۵ |
| xhttp | ۲ |
| ssh | ۱٫۵ |

- هر حالت فقط وقتی آماده نگه داشته می‌شود که حداقل یک پورت از آن استفاده کند (قبلاً همه همیشه آماده بودند).
- اتصال‌های آماده کمتر و دیرتر نو می‌شوند، و پیام‌های نگه‌داشتن اتصال کم‌تکرارتر شدند.
- reverse به جای ۸ اتصال منتظر، ۳ تا نگه می‌دارد. dns در حالت بی‌کار کمتر سؤال می‌فرستد.

**به‌روزرسانی:** روی **هر دو سرور** `pol update` بزنید.

<details open><summary>English</summary>

**Honest traffic labels**, in three measured parts: on transfers (about +1% for the TCP modes), **per connection** (tls +3.5 kB, split +14 kB, obfs and mux +0.2 kB) and **a day idle**. `pol modes` and the menu show all three. New tags: "many short connections: web, apps" on mux, obfs and ssh; "big downloads" on split. For web and apps prefer mux or obfs, e.g. `pol mode 2088 auto:mux,obfs,tls,xhttp`.

**Much less idle traffic:**

- A mode is kept ready only while a port uses it.
- Smaller pools, refreshed less often; keepalives less frequent.
- reverse keeps 3 waiting connections, not 8; dns polls less when quiet.

Measured idle cost per mode, MB a day: tls 14, split 15, mux 24, ws 9, kcp 8, camo 7, quic 5, obfs 2.5, xhttp 2, ssh 1.5.

`internal/cost_probe_test.go` (`POL_COST=1`) measures these numbers.

**Update:** `pol update` on both servers.
