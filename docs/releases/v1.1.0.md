## منوی پل

- فقط **`pol`** را بزنید تا منوی شماره‌دار باز شود: وضعیت، اضافه و حذف پورت، لیست پورت‌ها، پینگ، تست سرعت، لاگ زنده، ری‌استارت، توقف و شروع، BBR، آپدیت، راه‌اندازی دوباره و حذف. روی سرور خارج، گزینه‌های توکن هم هست.
- اگر پل هنوز روی سرور راه‌اندازی نشده باشد، منو می‌پرسد این سرور خارج است یا ایران.
- `pol menu` هم همان منو را باز می‌کند. همهٔ دستورهای قبلی مثل `pol add 2088` مثل قبل کار می‌کنند.
- بعد از نصب، پیام آخر می‌گوید که با `pol` منو باز می‌شود.

**به‌روزرسانی:** روی هر دو سرور `pol update` بزنید.

---

<details open><summary>English</summary>

- Type **`pol`** on its own for a numbered menu: status, add and remove ports, list, ping, speed test, live logs, restart, stop/start, BBR, update, set up again and uninstall; the server's menu also shows and renews the token.
- On a machine that is not set up yet, the menu asks whether it is the server or the relay.
- `pol menu` opens the same menu; every command (`pol add 2088` and the rest) works as before.

**Update:** run `pol update` on both servers.

</details>
