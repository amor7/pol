# پل (pol)

**[English](README.md)**

**پل** پورت‌های TCP را از یک سرور به سرور دیگر، از داخل **یک تونل رمزگذاری‌شده**، منتقل می‌کند. کاربرها به سرور ایران وصل می‌شوند و اتصالشان طوری به سرور خارج می‌رسد که انگار مستقیم به خود آن وصل شده‌اند.

</div>

```
              ┌──────────── ایران ───────────┐                 ┌─────────── خارج ───────────┐
 کاربرها ────►│ relay  :2088  :8443  :2096 … │══ یک اتصال ════►│ server ──► 127.0.0.1:2088  │
              └──────────────────────────────┘   TLS (HTTP/2)  │            127.0.0.1:443   │
                                                               └────────────────────────────┘
```

<div dir="rtl">

- **نصب با یک دستور**، و هر پورت با یک دستور: `pol add 2088` و `pol del 2088`.
- **فقط یک اتصال بین دو سرور.** هر اتصال کاربر یک «جریان» داخل یک اتصال HTTPS است (برای سرعت، چند اتصال). از بیرون فقط یک اتصال HTTPS معمولی به یک وب‌سرور دیده می‌شود و اینکه کاربرها به چه چیزی وصل می‌شوند داخل آن پنهان می‌ماند.
- **امن.** سرور ایران فقط گواهی سرور خارج شما را قبول می‌کند (با اثر انگشت) و خودش را با یک رمز معرفی می‌کند. هر کس دیگری که وصل شود، یک صفحهٔ معمولی «404 Not Found» از nginx می‌بیند.
- **پایدار.** هر اتصال کاربر بافر خودش را دارد و یک کاربر گیرکرده بقیه را معطل نمی‌کند. اتصال قطع‌شده در چند ثانیه شناسایی و دوباره برقرار می‌شود. اگر پورتی دست برنامهٔ دیگری باشد، پل آن‌قدر تلاش می‌کند تا آزاد شود.
- **سبک.** یک فایل اجرایی، بدون هیچ وابستگی.

**فقط TCP.** هر چیزی که روی TCP کار کند پشتیبانی می‌شود: VLESS، VMess و Trojan روی TCP، WebSocket، gRPC، HTTPUpgrade، **Reality**، SSH، سرور بازی‌های TCP و پنل‌های وب. پروتکل‌های UDP مثل Hysteria2، TUIC، KCP، QUIC و WireGuard کار **نمی‌کنند**.

## نصب

دو سرور لینوکس (amd64 یا arm64) و دسترسی root روی هر دو لازم است.

**۱. روی سرور خارج** (همان سروری که x-ui یا سرویس‌های دیگرتان رویش است):

</div>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amor7/pol/main/install.sh) server
```

<div dir="rtl">

یک پورت آزاد برای تونل انتخاب می‌کند (اگر 443 آزاد باشد همان، وگرنه 8443 و...)، سرویس را راه می‌اندازد و یک خط دستور برای سرور ایران چاپ می‌کند.

**۲. روی سرور ایران**، همان خطی را بزنید که چاپ شد. چیزی شبیه این است:

</div>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amor7/pol/main/install.sh) relay pol1_eyJzIjoi... --ports 2088
```

<div dir="rtl">

تمام. حالا کاربرها با آی‌پی سرور ایران روی پورت 2088 وصل می‌شوند و به پورت 2088 سرور خارج می‌رسند.

**برای x-ui (سنایی) و پنل‌های مشابه:** اینباند را دست نزنید. فقط در کانفیگ کاربرها، آدرس سرور خارج را با آدرس سرور ایران عوض کنید. پورت همان می‌ماند.

اگر نصب را بدون آرگومان بزنید، می‌پرسد روی کدام سرور هستید. بعداً برای آپدیت، همان دستور نصب را بدون آرگومان دوباره بزنید.

## حالت‌های تونل

هر پورت می‌تواند حالت خودش را داشته باشد و پورت‌های مختلف می‌توانند حالت‌های متفاوتی داشته باشند:

| حالت | چطور کار می‌کند | کی استفاده کنیم |
|---|---|---|
| **tls** (پیش‌فرض) | هر اتصال کاربر یک اتصال TLS جدا به سرور دارد. چند اتصال از قبل آماده نگه داشته می‌شود تا کاربر منتظر نماند | انتخاب معمول: رمزگذاری‌شده و سریع، مخصوصاً روی مسیرهای پرافت و اینترنت‌هایی که سرعت هر اتصال را جدا محدود می‌کنند |
| **mux** | همهٔ اتصال‌ها داخل چند اتصال HTTP/2 | پنهان‌ترین حالت: از بیرون فقط یک اتصال HTTPS دیده می‌شود. روی مسیرهای پرافت کندتر است |
| **direct** | TCP ساده، مستقیم به پورت سرور خارج، بدون پل در وسط | سریع‌ترین. چیزی اضافه نمی‌کند، پس فقط رمزگذاری خود سرویس (Reality یا TLS) هست، و پورت باید از سرور ایران در دسترس باشد |

`pol speedtest` سرعت tls و mux را کنار هم می‌سنجد، با چهار اتصال هم‌زمان مثل یک گوشی، تا ببینید کدام برای مسیر شما بهتر است. tls و mux هر دو از همان یک پورت تونل استفاده می‌کنند و direct از پورت خود سرویس.

</div>

```bash
pol add 2088 --mode tls      # پورت‌های جدید پیش‌فرض tls هستند
pol mode 2088 mux            # عوض کردن حالت؛ اتصال‌های باز همان‌طور ادامه می‌دهند
```

## دستورها

روی هر کدام از دو سرور، فقط **`pol`** را بزنید تا منوی شماره‌دار باز شود و همهٔ کارهای زیر را از آنجا انجام دهید:

</div>

```
   pol v1.2.0  relay · running

    1) Status
    2) Add ports
    3) Remove ports
    4) List ports
    5) Change the tunnel mode of ports
    6) Ping through the tunnel
    7) Speed test (compares the modes)
    8) Logs (live - Ctrl+C to stop)
    9) Restart
   10) Stop
   11) Speed up the network (BBR)
   12) Update pol
   13) Set up again
   14) Uninstall
    0) Exit
```

<div dir="rtl">

یا دستورها را مستقیم بزنید:

روی **سرور ایران** (relay):

| دستور | کار |
|---|---|
| `pol add 2088` | پورت 2088 را به پورت 2088 سرور خارج منتقل می‌کند |
| `pol add 2088:443` | پورت 2088 اینجا را به پورت 443 سرور خارج منتقل می‌کند |
| `pol add 2080-2085` | یک بازه پورت، هر کدام به همان پورت |
| `pol add 2088 8443 2096` | چند پورت با هم (با کاما هم می‌شود) |
| `pol add 2088 --mode mux` | انتخاب حالت تونل (`tls`، `mux`، `direct`) |
| `pol mode 2088 tls` | عوض کردن حالت پورت‌های موجود |
| `pol del 2088` | حذف پورت (یا `rm`؛ بازه هم قبول می‌کند) |
| `pol list` | لیست پورت‌ها با اتصال‌های فعال و ترافیک |
| `pol ping` | زمان رفت‌وبرگشت از داخل تونل |
| `pol speedtest [MB]` | مقایسهٔ سرعت حالت‌های tls و mux در هر دو جهت |

روی **سرور خارج** (server):

| دستور | کار |
|---|---|
| `pol token` | دوباره چاپ کردن توکن و دستور نصب سرور ایران |
| `pol token --new` | ساختن رمز جدید؛ سرورهای ایران توکن جدید لازم دارند |

روی **هر دو**:

| دستور | کار |
|---|---|
| `pol status` | وضعیت اتصال، پینگ، پورت‌ها و ترافیک |
| `pol logs [-f] [-e]` | لاگ سرویس (`-f` زنده، `-e` فقط خطاها) |
| `pol restart` · `pol stop` · `pol start` | کنترل سرویس |
| `pol tune` | روشن کردن BBR و بزرگ کردن بافرهای TCP (روی هر دو سرور پیشنهاد می‌شود) |
| `pol update` | نصب آخرین نسخه، با بررسی checksum |
| `pol uninstall` | حذف پل |

پورت‌هایی که اضافه یا حذف می‌کنید **همان لحظه** اعمال می‌شوند و کاربرهای بقیهٔ پورت‌ها قطع نمی‌شوند. اگر ufw فعال باشد، پورت‌ها خودکار در آن باز و بسته می‌شوند. اگر شرکت سرورتان در پنل سایتش فایروال دارد، پورت‌ها را آنجا خودتان باز کنید: پورت تونل روی سرور خارج، و پورت‌های منتقل‌شده روی سرور ایران.

## تنظیمات

همه‌چیز در `/etc/pol/config.json` است و فقط root به آن دسترسی دارد. دستورها خودشان آن را ویرایش می‌کنند. اگر دستی ویرایشش کنید، سرور ایران ظرف دو ثانیه تغییر را می‌گیرد.

- `relay.conns`: تعداد اتصال‌های موازی تونل (پیش‌فرض ۲). روی مسیرهای طولانی یا پرافت، بیشتر کردنش می‌تواند کمک کند.
- `relay.sni` و `server.sni`: اسمی که سرور ایران موقع اتصال اعلام می‌کند (پیش‌فرض `example.com`). کسی چکش نمی‌کند، ولی فیلترینگ ایران اتصال TLS بدون اسم را قطع می‌کند.
- `server.any_target`: سرور خارج به‌طور پیش‌فرض فقط به پورت‌های خودش (`127.0.0.1`) وصل می‌کند. اگر `true` بگذارید، `pol add 2088:10.0.0.5:443` به ماشین‌های دیگر هم می‌رسد.

چند سرور ایران می‌توانند هم‌زمان از یک توکن استفاده کنند.

## نصب بدون دسترسی به گیت‌هاب

اگر سرور ایران به گیت‌هاب دسترسی ندارد، فایل `pol-linux-amd64` را از [صفحهٔ نسخه‌ها](https://github.com/amor7/pol/releases) روی کامپیوتری که دسترسی دارد دانلود کنید، روی سرور کپی کنید و بزنید:

</div>

```bash
install -m 755 pol-linux-amd64 /usr/local/bin/pol && pol setup relay pol1_... --ports 2088
```

<div dir="rtl">

آپدیت‌ها هم همین‌طور: `pol update --file pol-linux-amd64`
