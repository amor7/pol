# پل (pol)

**[English](README.md)**

**پل** پورت‌های TCP و UDP را از یک سرور به سرور دیگر، از داخل یک **تونل رمزگذاری‌شده**، منتقل می‌کند و برای هر پورت **هشت حالت تونل** مختلف دارد. کاربرها به سرور ایران وصل می‌شوند و اتصالشان طوری به سرور خارج می‌رسد که انگار مستقیم به خود آن وصل شده‌اند.

- **نصب با یک دستور**، هر پورت با یک دستور (`pol add 2088`)، یا فقط `pol` برای منو.
- **هشت حالت، هر کدام یک راه متفاوت.** اگر یکی روی مسیر شما کند یا بسته بود، یکی دیگر جواب می‌دهد. `pol speedtest` همه را روی سرورهای خودتان می‌سنجد و رتبه‌بندی می‌کند.
- **TCP و UDP.** VLESS، VMess، Trojan، Reality، WebSocket، gRPC و SSH، و با پورت‌های UDP: Hysteria2، TUIC، WireGuard و KCP.
- **امن.** سرور ایران فقط گواهی سرور خارج شما را قبول می‌کند و خودش را با رمز معرفی می‌کند. هر کس دیگری صفحهٔ خطای معمولی nginx می‌بیند، و در حالت obfs هیچ جوابی نمی‌گیرد.
- **پایدار.** کاربر گیرکرده بقیه را معطل نمی‌کند، اتصال‌های قطع‌شده دوباره برقرار می‌شوند، و پورت اشغال‌شده آن‌قدر امتحان می‌شود تا آزاد شود.

## نصب

دو سرور لینوکس (amd64 یا arm64) و دسترسی root روی هر دو لازم است.

**۱. روی سرور خارج** (همان سروری که x-ui یا سرویس‌های دیگرتان رویش است):

</div>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amor7/pol/main/install.sh) server
```

<div dir="rtl">

یک پورت آزاد برای تونل انتخاب می‌کند، سرویس را راه می‌اندازد و یک خط دستور برای سرور ایران چاپ می‌کند.

**۲. روی سرور ایران**، همان خطی را بزنید که چاپ شد:

</div>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amor7/pol/main/install.sh) relay pol1_eyJzIjoi... --ports 2088
```

<div dir="rtl">

تمام. کاربرها با آی‌پی سرور ایران روی پورت 2088 وصل می‌شوند و به پورت 2088 سرور خارج می‌رسند.

**برای x-ui (سنایی):** اینباند را دست نزنید. فقط در کانفیگ کاربرها، آدرس سرور خارج را با آدرس سرور ایران عوض کنید. پورت همان می‌ماند.

## حالت‌های تونل

هر پورت حالت خودش را دارد و هر وقت بخواهید با `pol mode <پورت> <حالت>` عوضش می‌کنید.

| حالت | چطور می‌رود | به درد چه می‌خورد |
|---|---|---|
| **tls** (پیش‌فرض) | هر اتصال کاربر یک اتصال TLS جدا، از بین اتصال‌های آماده | انتخاب معمول: رمزگذاری‌شده و سریع |
| **split** | هر اتصال کاربر هم‌زمان روی ۴ اتصال TLS پخش و آن طرف به ترتیب سرهم می‌شود | اینترنتی که سرعت هر اتصال را جدا محدود می‌کند: حتی یک دانلود بزرگ به سرعت چند اتصال می‌رسد |
| **quic** | جریان‌های یک اتصال QUIC روی UDP | مسیرهای پر از بسته‌گم‌شدن: هر بستهٔ گم‌شده فقط جریان خودش را معطل می‌کند |
| **mux** | همهٔ اتصال‌ها داخل چند اتصال HTTP/2 | پنهان‌ترین حالت: از بیرون فقط یک اتصال HTTPS طولانی |
| **obfs** | TCP با رمز AES، بدون دست‌دادن TLS، با بستهٔ تصادفی | وقتی TLS به سرورهای خارجی هدف فیلترینگ است: از همان اولین بایت شبیه دادهٔ تصادفی است |
| **ws** | یک WebSocket برای هر اتصال، مثل یک صفحهٔ وب | رد شدن از **Cloudflare** وقتی آی‌پی سرور خارج فیلتر شده (`pol cdn`) |
| **reverse** | **سرور خارج به سرور ایران وصل می‌شود** و اتصال‌ها را آماده نگه می‌دارد | وقتی اتصال از ایران به خارج بسته است ولی برعکسش باز است (`pol reverse`) |
| **direct** | TCP یا UDP ساده مستقیم به پورت خارج، بدون پل در وسط | سریع‌ترین. فقط رمزگذاری خود سرویس می‌ماند |

همهٔ حالت‌ها به‌جز reverse و direct از همان یک پورت تونل سرور خارج استفاده می‌کنند (TCP، و UDP برای quic). سرور از روی اولین بایت‌ها می‌فهمد هر اتصال کدام حالت است.

### کدام را انتخاب کنیم؟

روی سرور ایران `pol speedtest` بزنید. همهٔ حالت‌ها را از مسیر واقعی شما، با چهار اتصال هم‌زمان مثل یک گوشی، می‌سنجد و می‌گوید کدام سریع‌تر است. بعد پورت را روی همان بگذارید: `pol mode 2088 split`.

### پورت UDP

</div>

```bash
pol add 443/udp --mode quic        # پورت UDP (برای Hysteria2، TUIC، WireGuard و KCP)
pol add 2096 --both                # TCP و UDP روی یک پورت
```

<div dir="rtl">

### حالت reverse

روی سرور ایران `pol reverse` بزنید. یک پورت باز می‌کند و یک خط `pol link pol1r_...` چاپ می‌کند. آن را روی سرور خارج بزنید. بعد روی سرور ایران: `pol mode 2088 reverse`.

### Cloudflare برای حالت ws

یک دامنه در Cloudflare به آی‌پی سرور خارج وصل کنید (ابر نارنجی روشن) و SSL/TLS را روی **Full** بگذارید. بعد روی سرور ایران:

</div>

```bash
pol cdn my.domain.com
pol mode 2088 ws
```

<div dir="rtl">

پورت تونل سرور خارج باید یکی از پورت‌هایی باشد که Cloudflare قبول می‌کند: 443، 2053، 2083، 2087، 2096 یا 8443.

## دستورها

روی هر کدام از دو سرور، فقط **`pol`** را بزنید تا منوی شماره‌دار باز شود. یا دستورها را مستقیم بزنید:

روی **سرور ایران**:

| دستور | کار |
|---|---|
| `pol add 2088` | انتقال پورت 2088 به پورت 2088 سرور خارج |
| `pol add 2088:443` | پورت 2088 اینجا به پورت 443 خارج |
| `pol add 2080-2085` | یک بازه پورت |
| `pol add 443/udp` · `pol add 2096 --both` | پورت UDP؛ TCP و UDP با هم |
| `pol add 2088 --mode split` | انتخاب حالت (پیش‌فرض `tls`) |
| `pol mode 2088 quic` | عوض کردن حالت پورت‌های موجود |
| `pol del 2088` | حذف پورت (`2088/udp` فقط UDP) |
| `pol list` | لیست پورت‌ها با اتصال‌ها و ترافیک |
| `pol speedtest` | سرعت همهٔ حالت‌ها و رتبه‌بندی |
| `pol ping` | پینگ از داخل تونل |
| `pol reverse` · `pol reverse off` | راه‌اندازی یا حذف حالت reverse |
| `pol cdn <دامنه>` · `pol cdn off` | فرستادن حالت ws از Cloudflare |

روی **سرور خارج**:

| دستور | کار |
|---|---|
| `pol token` | دوباره چاپ کردن توکن |
| `pol token --new` | رمز جدید (سرورهای ایران توکن جدید لازم دارند) |
| `pol link <توکن>` · `pol unlink <آدرس>` | وصل یا قطع کردن سرور ایران در حالت reverse |

روی **هر دو**:

| دستور | کار |
|---|---|
| `pol status` | وضعیت همهٔ حالت‌ها، پورت‌ها و ترافیک |
| `pol logs [-f] [-e]` | لاگ سرویس |
| `pol restart` · `pol stop` · `pol start` | کنترل سرویس |
| `pol tune` | روشن کردن BBR (روی هر دو سرور پیشنهاد می‌شود) |
| `pol update` | نصب آخرین نسخه |
| `pol uninstall` | حذف پل |

پورت‌ها همان لحظه اعمال می‌شوند و کاربرهای بقیهٔ پورت‌ها قطع نمی‌شوند. اگر ufw فعال باشد، پورت‌ها خودکار در آن باز و بسته می‌شوند. اگر شرکت سرورتان در پنل سایتش فایروال دارد، پورت‌ها را آنجا خودتان باز کنید: روی سرور خارج پورت تونل برای **TCP و UDP**؛ روی سرور ایران پورت‌های منتقل‌شده (و پورت reverse اگر استفاده می‌کنید).

## نصب بدون دسترسی به گیت‌هاب

فایل `pol-linux-amd64` را از [صفحهٔ نسخه‌ها](https://github.com/amor7/pol/releases) روی کامپیوتری که دسترسی دارد دانلود کنید، روی سرور کپی کنید و بزنید:

</div>

```bash
install -m 755 pol-linux-amd64 /usr/local/bin/pol && pol setup relay pol1_... --ports 2088
```

<div dir="rtl">

آپدیت‌ها هم همین‌طور: `pol update --file pol-linux-amd64`
